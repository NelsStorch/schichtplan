Le Cevi Schichtplan est un projet entièrement bénévole. La plupart de vos questions trouveront une réponse plus rapide auprès de votre CO ou de votre direction de section.

## Qui contacter ?

| Question | Le meilleur interlocuteur |
| --- | --- |
| Horaires, lieu, équipement à apporter, échange de créneau | Le **CO** de l'événement (indiqué en haut de l'événement) |
| Erreur de section ou de branche, rôles, page d'accueil verrouillée | La **direction** de votre section |
| Données incorrectes issues de la Cevi.DB | Le ou la **gestionnaire Cevi.DB** de votre section |
| Mot de passe oublié, anomalie technique dans le plan de créneaux | Les **administrateurs** du plan de créneaux, voir ci-dessous |
| Supprimer un profil avec prénom/surnom seul | Sur la page de profil dans l'onglet **Sécurité & données**, avec **Demander la suppression** |

Pour nous aider à résoudre un problème technique, pensez à préciser :

- l'adresse de la page web sur laquelle l'erreur est survenue
- ce que vous étiez en train de faire et ce que vous attendiez
- une capture d'écran du message affiché
- s'il s'agit d'un smartphone ou d'un ordinateur, ainsi que le navigateur utilisé

N'envoyez jamais de mot de passe.
